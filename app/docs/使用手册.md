## 1. 系统简介

**青龙智能采集中心**是数据采集平台的前端工作台，覆盖「看总览 → 配采集链路 → 发任务 → 看落表数据 → 追溯运行 → 运维监控」的完整闭环，把采集链路的**配置、资产、规则、指标、运行、监控**整合到一个入口。

系统采用 Vue 3 + Element Plus 构建，为真实后端接入（非演示 mock）。用户通过浏览器访问，无需安装客户端。

### 1.1 核心概念

| 概念 | 说明 |
|---|---|
| **网站** | 采集对象的最上级归属（如某个财经网站），下挂多个采集源。 |
| **源** | 具体的采集单元（如某网站的某个栏目、某个账号），是发起抓取、配置流程的基本单位。一个源可以关联多条流程。 |
| **流程** | 一条采集链路（节点 + 连线 + 配置）。流程可被多个源共用，决定源跑哪条采集链路。有「草稿 / 已发布」版本。 |
| **来源组** | 配置相同的一批源组成的技术分组。组绑定流程，成员自动继承组流程；源入组后其自身流程绑定停用。 |
| **实体表 / 表** | 采集结果落地的数据结构（表定义 + 字段），采集出的数据以行为单位落在表中。 |
| **规则** | 采集链路上的表达式处理（清洗 / 校验 / 打标 / 过滤），配合测试集与发布门禁。 |
| **指标** | 基于数据集（dataset）与指标定义（measure）的统计口径。 |
| **任务** | 一次采集执行实例，有唯一的任务 ID，可追溯节点明细与结果。 |

### 1.2 主要模块一览

| 模块 | 入口 | 用途 |
|---|---|---|
| 首页总览 | `#/overview` | 采集资产 KPI、趋势、占比、告警，并下钻到各模块。 |
| 源管理 | `#/collect` | 系统目录 / 我的分组 / 我的视图 / 我的收藏 / 最近打开。 |
| 流程中心 | `#/flows` | 流程列表、编辑、版本、关联源。 |
| 流程画布（源工作区） | `#/canvas` | 单个源的流程编辑、发起抓取、结果查看。 |
| 规则资产 | `#/rules` | 规则组、规则、函数测试器、发布门禁；参数中心。 |
| 指标中心 | `#/metrics` | 指标数据集与指标定义浏览。 |
| 数据中心 | `#/data` | 数据查询、表结构维护、导入导出。 |
| 文件中心 | `#/files` | 网站采集的文件资源查看与预览。 |
| 任务中心 | `#/tasks` | 全局任务查询、详情与重发。 |
| 数据同步 | `#/sync` | 把采集库数据按字段映射与定时策略同步到目标环境。 |
| 监控中心 | `#/monitor` | 数据源告警、队列、任务实例与统计。 |
| 系统设置 | `#/settings` | 节点类型、分类目录、来源组、运行机器、代码仓库、部署配置等。 |

## 2. 访问入口与环境

系统有**两套部署环境**，可通过顶栏徽标一眼区分：

| 项 | 正式平台（217 / 生产） | 133 平台（测试） |
|---|---|---|
| 访问地址 | `http://47.120.11.60:2806/sjcj/` | `http://47.120.11.60:2807/sjcj/` |
| 业务后端 | `118.25.96.217:9999` | `115.227.21.133:9999` |
| 顶栏徽标 | 红色「后台环境 118.25.96.217 · 允许新建，禁止改删」 | 蓝色「后台环境 115.227.21.133」 |
| 写保护 | **有**：可新建，禁止改删 | 无：可改可删 |

> ⚠️ **正式平台（2806）有写保护**：允许新建（网站、源、配置等），但**禁止修改、删除、启停、发抓取、覆盖流程等破坏性操作**。在正式平台误操作会被拦截并提示。日常联调、验证在 133 平台（2807）进行。

登录后打开任一页面，地址栏哈希即对应模块入口（见[模块入口速查表](#20-模块入口速查表)），可直接加书签或分享。

## 3. 登录与账号

### 3.1 登录

1. 打开访问地址，进入登录页（`#/user/login`）。
2. 输入**账号**（用户名或邮箱）、**密码**、**图片验证码**（看不清可点图片或右侧刷新按钮换一张）。
3. 点击「登 录」。

- 登录成功默认进入首页总览（`#/overview`）；若你是通过带 `redirect` 参数的链接进入，登录后回到原页面。
- 登录失败会在表单顶部以红条提示，并**约 1 秒后自动刷新验证码**，请重新输入。
- 密码在传输前经过双重加密，验证码用于防止暴力破解。

### 3.2 账号菜单（顶栏右侧头像）

点击顶栏右上角**头像**（显示账号前 4 字）展开菜单：

| 菜单项 | 说明 |
|---|---|
| 修改密码 | 打开弹窗：输入原密码、新密码、确认新密码（确认与第二次输入一致即可），提交后生效。 |
| 退出登录 | 弹出确认「真的要注销登录吗 ?」，确定后登出并回到登录页。 |

### 3.3 会话有效期与失效处理

- 登录凭据本地保留 **7 天**，过期后需要重新登录。
- 会话失效（后端判定登录过期 / 未授权）时，页面会弹出「登录失效，请重新登录」提示框——该提示框**没有关闭 / ESC 出口**，点击「重新登录」后回到登录页并带上原地址，登录后跳回。
- 修改密码后，如当前会话失效，按上述方式重新登录即可。

### 3.4 账号角色

系统目前区分两种角色：

| 角色 | 说明 |
|---|---|
| **admin（管理员）** | 可执行写操作：新建 / 编辑 / 删除 / 启停 / 发抓取 / 重发任务 / 参数维护 / 来源组维护等。 |
| **read（只读）** | 只能查看与查询，写类按钮隐藏或禁用并提示无权限。 |

> 当前菜单对两种角色都可见（暂无按菜单权限码收敛），权限差异主要体现在**能否执行写操作**。具体见[权限与安全](#17-权限与安全)。

### 4.4 通用交互约定

- **详情一律右侧抽屉**：数据表、源、数据行、配置、规则、流程等实体详情使用右侧 `el-drawer`，保留当前列表上下文；居中弹窗仅用于选择、导入、确认提示和短流程编辑。
- **滚动**：页面尽量保持单一主滚动容器，抽屉与表格滚动方向清晰可预期。
- **危险操作二次确认**：删除、发抓取、启停、清空、重发等均弹确认框，部分要求输入表名等增强确认。
- **刷新语义**：列表刷新按当前筛选条件、当前页和分页大小重新查询，不提供「清除缓存」入口。

## 6. 源管理

源管理（`#/collect`）是管理「网站与源」的核心模块。顶部页签：

| 页签 | 内容 |
|---|---|
| 系统目录 | 全平台源列表（分类树 + 表格），日常浏览与批量操作的主入口。 |
| 我的分组 | **全平台共用、只读**的来源组视图（内容来自「系统设置 → 来源组」，维护在系统设置）。 |
| 我的视图 | **仅自己可见**的源列表查询视图（筛选条件 + 显示列 / 排序），可建多个。 |
| 我的收藏 | 我收藏的源（复用源列表，带收藏过滤）。 |
| 最近打开 | 最近打开过的源（复用源列表，带最近过滤）。 |

页签右侧有「默认进入（本机）」下拉：可设置打开源管理时默认进入**系统目录 / 我的分组 / 我的视图 / 上次使用的目录**（仅保存在当前账号、当前浏览器）。

> 旧的「配置列表」「表 ID 列表」「参数」页签已迁移：表 ID 列表 → 数据中心（`#/data?tab=entry`），参数 → 规则资产（`#/rules?tab=param`），旧链接自动跳转。

### 6.1 系统目录

系统目录是全平台源列表的主入口，有**卡片视图**与**列表视图**两种切换（工具条切换）。

**卡片视图**（一卡 = 一个网站）：

- 搜索网站名 / 源名（300ms 防抖）；分类树多选（懒加载）；标签筛选。
- 统计标签：「网站 / 源 / 出错源 / 空网站 / 告警网站」——点「出错源」「空网站」可切换只看它们。
- 卡片操作：左击进网站源视图；源 chip 进源概览；「+N」浮层可搜索源并含「全部」入口；☆ 收藏网站（后端存储，同账号跨设备）；「⋯」/ 右键菜单 → 编辑网站信息（**无删除**）。
- 底部「数据 N 条」点进数据视图。
- 新建 / 编辑网站共用弹窗：网站名称、所属分类（树形可搜索单选）、标签。

**列表视图**（一行 = 一个源）：

- **查询**：多行「字段 + 条件 + 值」（自动识别源 ID / 名称 / URL，多行 AND；按名称查空时提示「改按 URL 查」）。
- **筛选**：网站、来源组、状态、标签、数据量 ≤。
- 表头排序（源 ID / 数据 / 最近任务 / 最近成功）。
- 行内：☆ 收藏源、源 ID / 名称进详情、URL 外链、标签与备注点击行内编辑、数据量下钻数据视图、流程配置列（「组统一」/「单源」）。

> 网站列表一次拉取 2000 条、前端排序分页；「出错源」为前端按 errorCount 过滤。点击源名 / 源 ID 进入该源的**源工作区（流程画布）**。

**批量操作**（勾选后出现）：

| 操作 | 说明 |
|---|---|
| 发任务 | 对勾选的源发起抓取；未勾选 = 按当前筛选条件全量收集。有参数源弹参数框；≤ 2 个直接发；> 2 个二次确认。提交走右下作业条，可暂停 / 中止（已发不撤回），失败批次可「重试失败批次」。 |
| 导出 | 按当前查询条件全量导出 xlsx（非当前页 / 勾选）。 |
| 添加标记 | 追加标签 / 清空标签 / 批量设置备注 / 清空备注（后三者二次确认）。 |
| 启用 / 停用 | 二次确认。 |
| 选中来源 ▾ | 源流程配置（勾选 1 个）/ 调整来源组 / 指定流程运行一次。 |

> 勾选只作用于**当前页**；翻页 / 重查会清空勾选（不支持跨页批量）。

**指定流程运行一次**：只对这些源当前生效的流程下发一次任务，不影响定时与默认流程。**源流程配置**：独立源可配置关联流程多选 + 默认流程单选 + 绑定启停（启用须先设默认流程）；组内源只读显示「统一使用组流程」，可「查看组配置」「退出来源组」（退出后旧绑定不恢复，需重配独立流程）。**调整来源组**：勾选的源须同属一个组才可操作；支持「按当前筛选范围」批量调整——**无任何筛选条件时红色警告 + 二次确认**（超 2 万个后端拒绝），生产环境仅支持按勾选调整。

**来源组说明**：源入组后，其自身的流程绑定全部停用，由组的流程统一接管；组内源要单独配流程须先「退出来源组」，退组后需重新配置独立流程才能运行。

### 6.2 我的视图

「我的视图」是用户自己保存的一套**源列表查询**（筛选条件 + 显示列 / 排序），一个人可建多个，**只有自己能看到**，不影响源本身与运行。

- 左栏：视图列表（名称、当前符合条件的源数、★ 默认进入）+「＋ 新建视图」；底部提示「视图只有你自己能看到；之后新增的源只要符合条件会自动出现」。
- 右栏：视图名 +「🔒 仅自己可见」+ 条件摘要 + 条件栏 + 源表格。
- 修改了条件 / 显示设置后出现「有未保存的修改」，可**保存**（覆盖）、**另存为**（新视图）、**撤销修改**；切换视图或离开时提醒。
- ⚙ 显示设置：显示哪些列、默认排序、每页条数（本期不支持拖拽调列顺序）。
- ⋯ 更多：重命名、设为默认进入、删除（只删视图，不动源）。
- 在**系统目录**工具条有「☆ 另存为视图」：把当前查询条件直接存成视图，可勾选「设为默认进入」。
- 右上「默认进入」下拉可加入各个视图。

> 当前视图**暂存本机**（后端接口排期中）；后端就绪后会切换为按账号存储，届时会提示把本机视图导入账号。换浏览器 / 换设备 / 清缓存后本机视图不自动同步。

### 6.3 我的收藏 / 最近打开

- **我的收藏**：在源列表行内点收藏图标，进入该页签可集中查看。地址 `#/collect?tab=favorite` 可存书签。
- **最近打开**：自动记录最近打开过的源。

## 7. 流程中心

流程中心（`#/flows`）是流程管理与编辑的主入口：流程列表 + 流程工作区（编辑）。

### 7.1 列表与筛选

- **筛选**：关键词（流程 ID / 名称 / 描述 / 备注 / 标签；纯数字自动按 ID 精确查、多 ID 逗号分隔）、排序（创建 / 更新时间、使用源数）、范围（全部 / 仅模板 / 仅普通）、分类树多选、标签。点「查询」触发、「清空」复位。
- **列**：流程 ID / 名称（带「已禁用」「模板」等徽标、版本号）、分类 / 标签、描述、使用源数（可点击下钻）、创建 / 更新时间、操作。
- **操作**（行内图标）：编辑流程、复制流程、关联到源、标记 / 取消模板、启用 / 禁用、删除。
- 顶部「新建流程」小表单（名称必填 + 分类 / 标签 / 描述），也可「从模板新建」。

### 7.2 流程编辑（工作区抽屉）

点击行的「编辑」或直接点行，打开右侧工作区抽屉，**内嵌流程画布（FlowBoard）+ 节点配置面板（NodeInspector）**，全程不出页面：

- 头部：流程名（可改）、ID、更新时间、**版本徽标（草稿 vX / 当前发布 vX）**、版本条、保存状态条（步骤保存中 / 失败可重试 / 待补配置）。
- 元信息：分类 / 标签 / 描述可编辑；**业务大类只读**；创建时间只读。
- 主体：可编辑的流程画布——节点增删改、连线、节点配置。
- 页脚：标记为模板 / 关联到源 / 保存草稿或保存流程 / 发布 vX。

### 7.3 流程版本（草稿 / 发布）

- **发布版只读**：已发布的流程版本只读，直接改会被拒。
- **自动生成草稿**：在发布版上做**第一次真实修改**时，自动从发布版生成草稿 Vn+1（无需先点「编辑草稿」）；只是打开查看不会生成草稿。
- 编辑后**保存**（步骤 800ms 防抖自动保存 + 「保存草稿」全量保存）；配置改动落库需要「节点配置 + 步骤」两步都保存。
- **发布**：点「发布 vX」→ 确认（新任务用新版本、运行中任务保持原版本）→ 发布。
- **放弃草稿**：确认后草稿里的修改全部丢弃，画布恢复为发布版本；尚未完成的草稿任务可能因版本失效而失败。
- 当前**不支持版本切换与归档回滚**；草稿被锁定（isLock=1）时只能查看，需到旧平台解锁。

### 7.4 关联源与使用范围反查

- **流程 → 关联源**：行「关联到源」打开选源弹窗：按名称 / ID 服务端搜索、按所属流程筛选、「仅看未关联」、批量粘贴 ID、全选本页 / 全选全部（≤ 2 万条）。**来源组内的源禁选**（显示「组统一配置：组名」）。确认时警告「这些源将共用该流程的配置并按它运行」。批量（每批 500）串行提交，可暂停 / 停止；已关联不回滚。
- **使用范围反查**：列表「使用源数 N 个」→ 弹出该流程下所有关联源（源 ID / 名称、状态、步骤数、数据量、最近任务），点行进入该源工作区；「在源视图中查看全部」→ 当所有源同属一个网站时跳转到源列表视图。
- **删除挂源流程**：后端会拒绝直接删除，先引导「更换到目标流程」或「仅解绑并删除」，再删除。

### 7.5 流程中心与画布的衔接

- 流程中心内编辑走内嵌画布，不跳转 `/canvas`。
- 源画布顶部的「所属流程」入口 → 回到流程中心并带「返回源」返回条，点击回到该源的画布。
- `/canvas` 路由要求带 `sourceId` / `siteId` / `mode=new`，否则被拦回源管理。

## 8. 流程画布（源工作区）

流程画布（`#/canvas?sourceId=xxx` 或 `?siteId=xxx` 或 `?mode=new`）是**单个源 / 网站**的采集工作区：查看与编辑流程、发起抓取、查看结果与数据。从源管理点击源名进入。

### 8.1 入口与上下文

- **源工作区**：`#/canvas?sourceId=xxx`，带源上下文，可编辑流程、查看该源的数据 / 文件 / 任务 / 监控。
- **网站详情**：`#/canvas?siteId=xxx`（无 sourceId），只读聚合该网站的数据 / 文件 / 任务视图，没有流程编辑。
- **新建采集**：`#/canvas?mode=new` 打开新建网站 / 源向导。
- 路由要求带 `sourceId` / `siteId` / `mode=new` 之一，否则被拦回源管理。

### 8.2 布局

- **顶部**：视图切换器（**概览 / 流程 / 数据 / 文件 / 任务 / 监控** 六档）、网站 / 源切换、流程名与**流程标签栏**（该源的关联流程）、保存状态（顶部显示）、「发起抓取」按钮、版本条。
- **左侧**：源侧栏（同网站下的源列表，可搜索、切换源、右键操作）。
- **中间**：按视图展示——流程画布（编辑）或数据 / 文件 / 任务 / 监控等结果视图；中间列可收起 / 展开。
- **右侧**：节点配置检查器（流程视图中选中节点时展开，可收起成窄条、拖动调宽）。
- **页面级页签**：最多 8 个源 / 网站页签，切换源保持各自视图与现场。

**视图默认布局**：数据视图默认收起右侧配置区让出表格空间；流程视图默认展开配置区。

### 8.3 流程画布编辑

**添加节点**（6 种入口）：

| 入口 | 说明 |
|---|---|
| 节点右键菜单「添加节点」 | 在当前节点旁添加。 |
| 画布空白处右键 | 打开节点库浮层添加。 |
| 画布左上「+」节点库 | 分组陈列 + 搜索。 |
| 节点左右「+」 | 添加**兄弟节点**。 |
| 分支列内「+」 | 追加到分支链尾。 |
| 连线上「+」 | 在父子节点之间插入（下游自动改挂到新节点）。 |

**节点卡片**：顶部节点类型名 + 运行态徽标（待运行 / 运行中 / 完成 / 失败 / 停用）+「已停止 / 规划中」徽标 + 步骤 ID（可点复制）；中部节点标题（可改）；底部 `⊞ 表名`（表血缘）、「条件」tag（进入条件悬停看全文）、「另有上级」tag（多上级标记）、状态。**孤儿节点**（解析不出上游）带「孤儿·关联」按钮，需手动选择挂靠目标后才能正常保存。

**右键菜单**：添加节点 / 复制节点（副本**必生成新配置**）/ 上移 / 下移 / 运行·停止 / 运行此节点 / 删除节点（二次确认）。

**拓扑规则**（主链 + 分支组）：

- 主链沿「单后继」走，遇分叉即停，分叉点以下整棵子树进分支组；分支链内再分叉形成嵌套。模型**无汇合概念**。
- ⚠️ **分支流程限制**：含分支的流程**拖动节点不会保存**（位置冻结），只能通过「+」新建分支 / 插入；节点名称、进入条件、配置照常保存。分支内节点拖不动。
- **多上级**：只按第一个上级连线，其余上级在卡片标「另有上级」，且该流程不自动重算挂接关系。

### 8.4 流程版本与保存（红线）

- **版本只读**：已发布版、锁定草稿只能查看——画布「+」不显示、不能拖拽 / 右键 / 删除，右侧检查器可滚动查看但不可改。直接改发布版：**第一次真实保存自动生成草稿 Vn+1**（无需先点「编辑草稿」）；发布后才影响新任务，**已启动任务继续用原版本**。
- **双落库**：右侧「保存」落**节点配置**，自动保存落**步骤**（800ms 防抖）。**没有步骤行的节点等于不存在**——保存后务必等顶部显示「已保存」。
- **保存状态**：顶部四态——`请先补全节点配置`（有未绑定配置的草稿节点）/ `保存中…` / `已保存 HH:MM` / `保存失败，点击重试`（失败自动退避重试：5s 起指数增长至 60s）。
- **未保存的草稿节点**：切换流程 / 源时弹提示（该节点尚未落库，切换后彻底消失，请先保存）。
- **发布 / 放弃草稿**：先自动保存；有未保存改动则拒绝并提示。发布二次确认（「新任务用新版本，已启动任务继续用原版本」）；放弃草稿二次确认（「草稿里修改全部丢弃，画布恢复为发布版本」）。

### 8.5 节点配置（右侧检查器）

选中节点后，右侧检查器顶部显示节点类型、启停开关、配置条（configId + 更换按钮），下方按节点类型显示页签：

| 页签 | 配置内容 |
|---|---|
| 节点配置 | URL、网页类型（列表 / 详情 / 附件）、业务类型、URL 参数绑定、运行设置（代理 / 断点续爬，勾选代理才展开账号密码）、登录配置清单、定时策略、参数源摘要。 |
| 表配置 | 采集类：输出表管理（固定产物类型输出表不可改）+ 非采集类产物明细；规则式（规则 / 监控 / 校验 / 翻译 / 打标签 / 摘要 / 音视频 / OCR / PDF）：输入表 + 输出表 + 入出参字段绑定。表编辑弹窗：新建按名称拼音生成物理表名 `TB_XXX`，字段类型仅 string / text / longtext，**已落库字段不可删、K 序不可改**，脏数据字段可删（二次确认）。 |
| 编排配置 | 规则处理：业务规则描述 → 系统提示词 → 生成脚本 / 保存脚本 → 脚本编辑工作台（全屏）→ 测试；监控节点：「监控方法」多选；AI 代码工作区：保存仓库 + 目录 + 列表 URL + 抓取提示词 → 生成代码 → 编辑 / 采用新结果 / 下载 / 历史版本 / 从仓库选 .py → 「保存并提交」自动提交 Git；OCR：样本上传 + 解析试跑；音视频：试跑 / 转文字 / 摘要等类型专属面板。 |
| 任务配置 | 有效输入表摘要 → 进入条件（字段 / 操作符 / 值，AND / OR 或表达式模式）→ 队列名称（缺省 `${sourceId}_main`）→ 参数绑定与出参列 → 上下文来源；定时策略（每天 / 每周 / 交易日定时 / 自定义 cron / 一次性，有 job 时显示启停开关与运行事实）。 |
| AI 对话 | 节点级助手（演示态，关键词匹配），快捷问题：解释配置 / 为何抓取失败 / 队列怎么填。 |

**门禁**：规则式节点须先在「表配置」绑完输入 / 输出表与字段，「编排配置」Tab 才可用。**更换配置**：ROOT 入口节点换配置影响该流程下全部源，需二次确认。

> 独立能力节点（浏览器 / 公众号抓取等）的输出表与队列由能力键自动锁定。节点 AI 对话与告警发送为演示态（告警「发送接口待接入」）。

### 8.6 发起抓取

- **入口**：顶部「发起抓取」（**仅主流程可启动**；辅助 / 补数据流程不能从正常入口启动；草稿未发布时禁用）。点击后：校验未保存节点（提示先保存）→ 跳过已停止 / 规划中 / 缺 URL 或输出表的节点 → 有登录节点时弹「选择登录配置」（本次任务生效，不改节点默认）→ 成功提示「已发起抓取 RUN-xxx」并驱动节点状态流转。
- **批量发任务**（源列表勾选 / 按条件全量）：勾选 ≤ 2 个且无参数**直接发**；无参数 > 2 个一句话确认；有参数弹参数框（按配置分组勾选、取值下拉、发送范围默认 / 不登陆 / 强制登陆、队列名）。
- **分批发送**：超过 500 个分批发送，**中途某批失败，已发出的不回滚**。
- **提交作业条**（右下角）：可暂停 / 结束（= 停止提交后续批次），**已提交的任务不撤销**；同时只允许一个作业；失败批次可「重试失败批次」；10 秒后自动收起。
- 生产（2806）有写保护，发抓取会被拦截；请到 133（2807）验证。

### 8.7 结果查看

**源概览**：指标卡（源状态、数据产出、任务记录数、异常检查数）+ 基本信息 + 五快捷入口（流程 / 数据 / 文件 / 任务 / 监控）+ 任务摘要与异常告警（前 5 条）。

**数据视图**：

- 顶部流程节点轨道（默认收起）：点节点切换查看对象；**节点右键**：发起本节点抓取 / 发后续任务 / 标「本次不发」（仅本次任务生效）/ 测试脚本。
- 浏览模式：按节点 / 按数据表；输入 / 输出表切换（可切时才可点）；表名点开表结构；行数。
- 筛选：SQL 条件 + 数据 ID / 父 ID 隐形筛选 chip；**改完点「查询」执行**（未执行有提示）。
- 数据操作：勾选行 → 「发起本节点任务」/「发后续」（同表多后继按各后继进入条件分流，确认弹窗列出分流目标）；「发全部（命中 N 条）」[实验性，上限 50 万条]；末节点可「从上一节点重跑」（需唯一上游）；**删除数据**（仅测试表，二次确认）。
- 导出（导出当前页 / 按当前查询条件导出 Excel / 查看 API 说明；**条件未执行时禁止导出**）；统计；全屏（Esc 退出）。
- 行交互：点行开**详情右侧抽屉**（字段列表、父行定位「父 ID ↗」、上级数据、文件类单元格站内预览、「下级」列点条数跳后继节点并带父 ID）；列控制（列选择 / 预设列 / 排序）。
- 网站 / 全部源态：纯查看；按表筛选；「反查源」按钮把命中的源写进源视图筛选（可再批量发任务 / 改标签）；**按网站导出 Excel 暂不支持**（需先选具体源）。

**文件视图**：筛选（文件名 / 展示名、类型、状态、表、SQL）；流程节点轨道筛选（仅点节点才开启）；表格列 K1–K10；点行开预览抽屉，行尾「详情」开详情抽屉；父文件返回。

**任务视图**（单源 / 网站全部源）：筛选、详情、重发见[任务中心](#13-任务中心)；数据 ID 可定位到数据视图。

**监控视图**：监控结果 / 监控配置两 Tab；监控结果为检查项列表 + 启停 + 校验历史日志（告警行标红）；监控配置含告警策略（总开关、策略列表、邮件 / 钉钉渠道——密钥不回显，发送接口待接入）。

**对比视图**：源侧栏行内 ⇔ 或底部「⇔ 对比」（跨站全局选择器）→ 双栏并排、各自独立加载同一数据视图 →「退出对比」回正常单栏。

## 9. 规则资产与参数中心

规则资产（`#/rules`）管理采集链路的规则表达式（清洗 / 校验 / 打标 / 过滤）。顶部有「规则 / 参数中心」两个 Tab。

### 9.1 规则

三栏布局：左栏规则组 + 发布门禁；中栏规则列表；右栏函数测试器。

**浏览与筛选**：关键词（规则名 / ID / 表达式）+ 状态（全部 / 已发布 / 草稿 / 已弃用）+ 按组筛选；分页 10 / 20 / 50。

**规则详情**（右侧抽屉）：状态、发布门禁三项（语法 / 引用 / 批测）、表达式、依赖共享配置、测试集（context → 期望 → 结果，阻断项标黄）、被引用关系。

**函数测试器**：输入表达式 + 上下文 JSON → 点「求值」→ 显示结果值、命中分支（IF-ELSE）、求值 trace；内置 3 个示例。支持 `IF`、`CONTAINS`、`LEN`、`NOT`、`AND`、`OR`、比较运算符与变量 / 字面量。

**发布校验与门禁**：

- 左栏门禁卡实时显示全局汇总：语法检查未通过数、共享配置引用告警数、批测通过率、待接口数。
- 发布须三项门禁全过（语法通过 + 引用通过 + 批测通过），否则拦截提示；通过后二次确认。
- 批量测试在 `evaluate` 接口未接通时进入「待接口」态。

> 说明：新建规则组、导入规则、发布、跑批测当前为演示占位（不写后端），真实规则发布能力随后端就绪上线。

### 9.2 参数中心

统一管理源导入与任务配置引用的参数。**仅 admin 可写**（read 只读）。

**参数类型**：列表、日期、日期序列、序列、数据库。

**操作**：

| 操作 | 说明 |
|---|---|
| 新建 / 编辑参数 | 右侧抽屉：名称、类型、按类型填值定义（列表用逗号 / 换行分隔；日期填 `$CUR_DATE,-1,yyyy-MM-dd` 表达式；序列填起止 + 步长；数据库填 SELECT 查询）、默认值；提交二次确认。 |
| 详情 / 查看值 | 定义按类型展示，「生成值预览」实时生成运行时值；列表型参数可新增 / 删除参数值。 |
| 复制 | 生成新 ID。 |
| 使用位置 | 反查该参数被哪些源、节点配置、任务参数引用（参数源绑定可跳转画布；配置绑定逐页核对、带进度）。 |
| 批量删除 | 勾选 + 二次确认。 |

**参数使用注意**：列表「值定义」列展示的是旧平台原始 valueDef；无清缓存入口，列表更新靠刷新重查当前条件。

## 10. 指标中心

指标中心（`#/metrics`）用于浏览指标数据集（dataset 层）与指标定义（measure 层）两层结构及口径回溯。

三栏布局：

- **左栏**：数据集树（全部数据集 / 各数据集），展示名称、状态（就绪 / 过期 / 构建中）、来源表、字段数、更新时间；点击联动右侧列表。
- **中栏**：指标列表（名称、周期、负责人、画布引用数、发布门禁状态）。
- **右栏**：指标详情——来源数据集、轻编辑器只读预览（聚合 = 口径、维度）、发布门禁三项（来源表字段存在 / SQL 条件白名单 / 结果回溯）、结果回溯链路（dataset → table → source → task 芯片链）。

当前为**只读浏览**：顶栏「新建指标 / 批量维护 / 口径校验」为演示占位；回溯链路跳转运行记录为二期功能。

## 13. 任务中心

任务中心（`#/tasks`，原「运行记录」）用于全局任务查询、详情与重发。旧路径 `#/runs` 自动跳转。

### 13.1 查询

- **默认条件：今天 + 异常**（用户拍板，避免只按创建时间查导致的慢查询）。
- 筛选：源、节点、字段 ▾ + 输入框（任务 ID / 数据 ID / 任务 URL）、创建时间区间（快捷键：今天 / 近 3 天 / 近 7 天）、状态（全部 / 完成 / 运行中 / 异常）、队列名。
- 筛选是「草稿」：改完点**查询**才生效（有「条件已修改，点查询执行」提示）；输入框回车即查。
- **清空 / 刷新 / 自动刷新开关**（默认关，开启后每 10 秒按已生效条件静默重拉，离开页面即停）。
- **没有任何条件时不发请求**，提示先选条件。

> **查询慢提示**：只按创建时间查询后端较慢（索引问题，后端已提需求）。请尽量带源 / 状态等条件；查询超过 2 秒显示「已等待 N 秒」。

### 13.2 列表与详情

- **列**：任务 ID、所属源、流程节点、任务名称、数据 ID、任务 URL、队列、类型、状态（运行中转圈 / 完成 / 异常）、创建时间、操作。
- 点击任务 ID → 详情抽屉（右侧）：标识信息（任务 ID 可复制、数据 ID 可定位、所属源、流程节点、队列、父任务 ID、文件 ID、任务类型、状态、任务 URL）、执行时间（生成 / 开始 / 结束 / 更新）、排错详情（执行结果、入参、上下文变量，JSON 自动格式化可复制）。
- 点击数据 ID 可定位到源画布数据视图该行；点击队列可按该队列筛选。

### 13.3 重发

- **仅 admin 显示**「重发」。
- 二次确认（「将任务重置为待发送，重新排队执行」）→ 提交后任务重新排队。
- 只重新排队，不修改、不删除任务数据。

## 14. 数据同步

数据同步（`#/sync`）把采集库（`sense_data`）里已有的表，按字段映射与定时策略同步到各客户自己的数据库 / 文件库。这是**独立于采集主链路的子系统**（后端 `/sync-platform/`）。

顶部 5 个页签：**同步任务 / 同步日志 / SQL 执行 / 建表 SQL / 环境配置**。

> 客户维度：普通账号客户固定为自己，admin 可切换客户。

### 14.1 同步任务

- **筛选**：客户（admin）、客户端、任务名称、源表名、目标表名、状态（已启用 / 已暂停）、任务 ID。
- **列**：ID、任务名称（点 → 只读明细）、源表、目标表、方式（SQL / CDC）、状态、同步频率 cron、最后同步成功、操作。
- **行操作**：
  - 编辑（右侧抽屉：任务名称、定时策略、5 段必填 SQL——查询目标数据起始 / 查询源数据 / 条件 / 保存数据 / 更新数据）；
  - 执行（启用且 SQL 型，二次确认）、参数执行（按时间起止 或 按 ID 起止）；
  - 关闭（启用态）、开启 / 删除（暂停态）。
- **删除**：弹窗必填目标表处理方式（0 不处理 / 1 备份表 / 2 删除表），二次确认。
- **批量**：批量参数执行 / 批量开启 / 批量关闭 / 复制到目标数据源（后三者二次确认）。

### 14.2 新建同步任务（向导）

入口「新建同步」→ `#/sync/create`（可带 `?tableName=` 预选源表）。四步：

1. **同步表配置**：客户（admin）→ 选源数据表 → 选目标数据库（联动 Schema、客户端）→ 填目标表名（自动去前缀）→ 「同步文件」开关（开则选目标文件库）。
2. **目标表配置（字段映射）**：行内编辑源列名 / 目标列名 / 数据类型 / 长度 / 备注 / 去重 / 默认值 / 删除；「增加列」；「同步实体」开关 = 目标列名按源列名回填；文件同步时多「映射文件列」。
3. **同步任务配置**：类型仅 SQL 查询；任务列表**最多 3 个**（默认名、cron 自动分散、SQL 模板自动生成）；开文件同步自动占一个名额。
4. **完成**：成功页 → 查看任务列表。

### 14.3 SQL 执行 / 建表 SQL

两页共用组件，用于在目标数据源上直接执行 SQL / 建表：

- **筛选**：客户、客户端、数据源编码、任务 ID（建表）、状态（待执行 / 执行完成）。
- **列表**：ID、客户端、数据源编码、SQL 内容（单行省略）、状态、执行结果（成功 / 失败：报错文本）、备注、时间、详情。
- **新增**：必填客户端、数据源编码（候选来自「环境配置 → 数据源配置」，可手输）、SQL 文本；建表可填关联同步任务 ID。
  - ⚠️ 提交前二次确认「确认下发执行」，明确提示「在所选数据源上直接执行，不能撤回，客户端不在线则上线后再执行」。
- 详情抽屉：字段描述 + 完整 SQL（可复制）+ 执行结果原文。

### 14.4 同步日志

默认查**当天** 00:00–23:59:59。筛选：客户、客户端、DB 名称、任务名称（远程搜索多选）、任务状态（运行中 / 完成 / 异常）、任务类型（定时 / 手动）、起止时间。

- **任务日志**：应同步 / 已同步 / 新增 / 更新数量、状态（异常显红）、耗时（仅完成态计算）、开始 / 完成时间、备注。
- **统计日志**：源表 / 目标表数量与统计 SQL，用于核对两端条数是否一致（行详情抽屉看 SQL）。

### 14.5 环境配置

- **客户端配置**：应用名称 + 定时 / 文件 / 实时同步三个开关（切换即时生效）、消息主题、扩展参数。
- **数据源配置**（只读）：名称、数据源编码、Schema、数据库类型（MySQL / PostgreSQL / Oracle）、类型（数据库 / 文件库）。

## 16. 系统设置

系统设置（`#/settings`）是平台配置入口，页签与地址栏 `?tab=` 同步。写操作多数仅 **admin**（read 只读并提示「仅可查看」）；「分类目录」对所有登录用户开放修改。

### 16.1 节点类型

旧平台「源类型」管理：列表（名称模糊查询）+ 右侧抽屉详情（类型 ID / 名称 / 配置队列 / 默认消息队列 / 排序 / 处理类型 / 参数 / 备注）+ 新建 / 编辑居中表单。

- **不提供删除**（后端未确认拒删契约）。
- 类型 ID 仅数字，不填系统分配；编辑只发改动字段。
- 新建 / 编辑仅 admin；保存后画布节点类型下拉即时生效。

### 16.2 分类目录

树形目录 + 懒加载 + 搜索；新增根分类 / 子分类、编辑、删除（二次确认，提示子分类级联移除不可撤销）、批量添加（分号 `;` 分割上下层，如「财经媒体;主流媒体」）、上移 / 下移排序。

> 无 admin 门槛，所有登录用户可改。

### 16.3 来源组

来源组决定组内源跑哪条流程，**修改影响全部成员**，**仅管理员可写**（非 admin 显示只读提示条；源管理「我的分组」页签即此页的只读视图）。

- **新建组**：编码（字母 / 数字开头，可含 `_ -`，最长 64）、名称、描述。
- **组资料抽屉**：编码 / 名称 / 描述 / 启用停用开关——**停用二次确认**「停用后全部成员不能启动新任务」；删除须先移空成员（有成员则提示不发请求）。
- **流程配置抽屉**：关联流程多选 + 选默认流程（整体替换）；绑定行状态开关（**启用绑定前须已设默认流程**）。
- **成员操作**：添加源（选源弹窗）、移出来源组 / 换到其他组（勾选多源，均二次确认；换组后统一用目标组流程）。
- 写操作带并发校验（revision）：两个会话同时改同一组，后保存的一方提示「已被修改，请刷新后重试」。
- 组停用后：关联流程不能保存、默认流程为空、成员不能再加入。

### 16.4 运行机器 / 机器配置 / Runner 版本 / 代码仓库 / 部署目录（Runner 管理套件）

> ⚠️ **仅本地开发环境显示**：这套 Runner 管理（运行机器、机器配置、代码仓库、部署目录、Runner 版本）依赖独立的 Runner 管理服务，生产网关（2806 / 2807）未转发该服务，因此**部署环境只显示节点类型 / 分类目录 / 来源组**三个页签。以下为本地开发态功能：

- **运行机器**：机器列表（IP / 安装目录 / 实例 / 状态 / 队列数 / Runner 版本 / 心跳，5 秒轮询）；远程接入码（生成一次性登记码）、设置 Runner 版本（下发目标版本，等待实例自动升级）、详情（含任务进程表）。
- **机器配置**（机器 × 部署目录绑定）：新增 / 编辑绑定（选机器、选部署配置、预览目标路径、任务环境 test / prod + 并发数）、启动 / 停止程序（仅在线机器可启动）、下发代码、部署目录跳转、移除（二次确认，同时停队列；部署配置与仓库代码保留）。
- **Runner 版本**：版本列表；「生成 Runner 版本」（发布 runner 源码，无变化时复用现有版本）。
- **代码仓库**：仓库列表（名称 / 配置类型 / 服务器路径 / Git 地址 / 分支 / 关联代码数 / 状态）；新建 / 编辑（**默认仓库不可改类型、不可停用**）、设为默认、启停、验证（连通性检查）、上传文件（≤ 20 个、单文件 5MB、总计 10MB；可选覆盖；有 remoteUrl 自动推送 Git）、文件浏览（分页 / 搜索 / 预览抽屉 / 删除，受保护文件不可删）、配置目录面板（目录增改、启停、移除——有代码引用时只能停用不能移除）。
- **部署目录**：部署配置列表 → 从流程节点新建（选流程 → 选已保存配置的节点）→ 目录映射编辑器（快捷格式：按配置 / 队列 / 网站 / 自定义；目录类型：默认 / 生产 / 测试；根目录格式变量 `{configId}/{queue}/{website}`；目标目录树：新建文件夹、拖拽移动、重命名、移除映射二次确认、设为执行入口 `.py`、展开整目录为独立文件——超 200 项拒绝；左侧仓库代码树关联到目录 / 替换关联 / 整目录展开；预览映射）。

## 19. 常见问题（FAQ）

**Q1：为什么在 2806 上点删除、发抓取没反应或提示失败？**
2806 是正式平台，有写保护（可新建、禁改删）。请在 133 平台（2807）进行修改、删除、发抓取等验证。

**Q2：为什么任务中心只按创建时间查很慢？**
后端按创建时间查询存在索引问题（已提需求）。请尽量带源 / 状态等条件，或使用默认的「今天 + 异常」。查询超过 2 秒会显示等待提示。

**Q3：我的视图怎么不见了？**
视图目前暂存本机（当前账号、当前浏览器）。换浏览器、清缓存、换设备后本机视图不会自动同步；后端接口上线后会切换为按账号存储。

**Q4：为什么源不能单独配流程？**
该源已加入来源组，组内源统一使用组流程。要单独配流程，先「退出来源组」，退组后需重新配置独立流程才能运行。

**Q5：为什么发布 / 保存被拦截？**
- 规则发布：须语法、引用、批测三项门禁全过。
- 流程：发布版只读，需先在发布版上做修改自动生成草稿后才能编辑保存；草稿被锁定（isLock=1）时只能查看。
- 流程发布 / 放弃前会自动保存，画布有未保存改动时会被拒绝并提示。

**Q6：为什么我在画布上拖了节点位置，保存后再打开又变回去了？**
含分支的流程**拖动节点不会保存**（位置冻结），请使用节点 / 连线上的「+」新建分支或插入节点；节点名称、进入条件、配置照常保存。

**Q7：为什么节点配置保存成功了，但流程里好像没有这个节点？**
节点需要「配置 + 步骤」**双落库**：右侧「保存」只落配置，自动保存才落步骤。请等顶部状态显示「已保存」再切换；出现「保存失败，点击重试」请先重试。

**Q8：为什么数据同步的 SQL 不能撤回？**
SQL 执行 / 建表任务提交后会在所选数据源上直接执行，不能撤回。提交前务必核对客户端、数据源与 SQL 内容。

**Q9：为什么「帮助」「通知」点了没反应？**
这两个入口暂未开放（占位）。

**Q10：会话过期了会怎样？**
会弹「登录失效，请重新登录」，点击后回到登录页；登录后自动回到原页面。

**Q11：为什么表格导出的是整表而不是我筛的条件？**
数据中心「导出 Excel」按当前查询条件导出全部（URL 直开下载链接），已带 SQL 条件 / 时间范围 / 数据 ID / 父 ID。若需要按当前页导出，用「导出 ▾ → 当前页 CSV」。画布源数据视图当前只有「统计 → 导出 CSV」（导统计结果），没有明细导出 Excel（后端能力限制，见需求记录）。
