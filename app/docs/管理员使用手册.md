## 2. 管理边界

新管理员先记住这几条：

1. 这是前端重构工程，不是后端采集执行器。
2. 当前默认全程 mock，不会真实发抓取、删数据、清缓存、清队列。
3. 写类和高危操作会二次确认，确认后也只返回演示回执，除流程定义本地保存外不落真实库。
4. 流程草稿保存在浏览器 `localStorage`，key 前缀为 `sjcj.flow.`，索引 key 为 `sjcj.flows.index`。
5. 凭据只展示引用和脱敏信息，不存储、不回显明文密码。
6. `/sjcj/` 是 WAN 公网入口下的隔离静态子路径，sjcj 部署只写 `/home/leo/sjcj/public`，不得写 WAN 项目目录。

## 5. 管理员日常流程

### 5.1 新建一条采集流程

1. 进入 `#/canvas`。
2. 点击画布顶部「＋ 新建流程」。
3. 在弹窗中输入采集需求，例如「公共网页数据抓取」，或点击快捷意图。
4. 查看推荐链路和推荐理由。
5. 点击「采用此流程」，或点击「从空白开始」。
6. 在画布中点击节点，右侧会显示节点配置。
7. 对采集节点补齐 URL、输出表、配置、参数等关键字段。

当前预置意图包括：

| 意图 | 生成链路 |
|---|---|
| 公共网页抓取 | 网页抓取列表 -> 网页抓取详情 -> 字段清洗 -> 落表。 |
| 登录站点抓取 | 需登录网页抓取 -> 详情抓取 -> 字段清洗 -> 落表。 |
| 文件下载解析 | 文件下载 -> 文件解析 -> 字段抽取 -> 落表。 |
| 公告规则采集 | 公告采集 demo 链路，包含规则处理和指标引用。 |

未命中意图时会生成空白流程。

### 5.2 编辑画布

常用操作：

| 操作 | 方法 |
|---|---|
| 添加节点 | 从左侧节点库拖到画布，或点击主链路插入点 `+`。 |
| 重排节点 | 拖动画布中的节点，或右键节点选择上移/下移。 |
| 复制节点 | 右键节点选择复制。 |
| 停用节点 | 右键节点选择启停。停用节点不会参与运行语义。 |
| 删除节点 | 右键节点选择删除。 |
| 配置节点 | 点击节点，在右侧检查器编辑基础、输入映射、参数、产物、试跑等信息。 |
| 配置连线子步骤 | 点击连线，在右侧编辑子步骤行、上下文和启停。 |

注意：

- OCR、AI 提取、发邮件、异常告警等节点当前标记为规划中，不能当作已真实跑通能力。
- 决策和并行相关能力首期以静态/草稿表达为主，真实执行拓扑仍是后续里程碑。

### 5.3 保存、发布与试跑

顶部按钮在流程画布页显示：

| 按钮 | 当前行为 |
|---|---|
| 保存草稿 | 调用 `flow/save` mock，把流程定义保存到浏览器 localStorage。 |
| 发布 | 先执行发布门禁，再保存并标记为发布候选。当前仍是演示态。 |
| 试跑 | 调用 runtime mock，生成 `RUN-TRIAL-*`，节点状态从处理中流转到完成，并生成一条落表数据。 |

发布门禁当前会拦截：

- 空流程。
- 采集节点缺少源 URL。
- 采集节点缺少输出表。

试跑后管理员应检查：

1. 画布节点状态是否变为完成。
2. `#/runs` 是否出现对应 run_id。
3. `#/data` 是否能看到带 run_id 的试跑落表数据。

### 5.4 管理采集资产

进入 `#/collect` 后有四个 tab：

| Tab | 用途 |
|---|---|
| 源列表 | 查看分类树、源列表、源详情、操作日志、任务、批量导入和批量操作。 |
| 配置列表 | 查看配置详情、发配置、复制、清缓存、删除等演示操作。 |
| 表 ID 列表 | 查看实体表与字段定义。 |
| 参数列表 | 查看参数类型与生成值预览。 |

源列表常用动作：

- 「新建采集源」打开四步向导：源信息 -> 输出表 -> 登录/参数 -> 确认。
- 「批量导入」提交模板源导入演示。
- 勾选源后可执行批量发任务、删除、启停、批量定时、批量改配置等演示动作。
- 点击源名称可打开源详情抽屉，查看 26 字段、凭据脱敏、子步骤和外部变更。

管理注意：

- 源、配置、参数的写类操作均会二次确认。
- mock 阶段不会真实修改后端数据。
- 删除、发抓取、发配置、清缓存等高危动作只作为交互与审批口径演示。

### 5.5 管理规则资产

进入 `#/rules`：

1. 左侧选择规则组。
2. 使用搜索和状态筛选定位规则。
3. 点击规则名打开详情抽屉，查看表达式、共享配置、测试集和引用关系。
4. 使用函数测试器输入表达式和 context，验证 IF、AND、OR、NOT、比较、CONTAINS、LEN 等支持的表达式。
5. 点击「发布校验」查看语法、引用、批测通过率和待接口状态。
6. 只有门禁为「可发布」的规则才允许走发布确认。

当前规则发布仍是演示态，不会真实发布到规则引擎。

### 5.6 查看指标、数据和运行

指标中心 `#/metrics`：

- 查看 dataset 和 measure 两层资产。
- 关注指标口径、负责人、引用链路和门禁状态。

数据查看 `#/data`：

- 选择数据表。
- 输入白名单字段条件。
- 查看行数据、表结构、列值指针和原始文件入口。
- 试跑产生的数据会叠加到静态 mock 数据上。

运行记录 `#/runs`：

- 按 run_id 查看运行时间线。
- 查看节点任务明细、输入、输出、trace、失败动作。
- 用于核对「画布试跑 -> 运行记录 -> 数据查看」是否贯通。

### 5.7 查看监控工具

进入 `#/tools`：

| 区域 | 管理用途 |
|---|---|
| 执行器健康 | 查看执行器、队列、缓存等健康摘要。 |
| MQ 状态 | 查看队列积压、失败数和状态。 |
| 同步状态 | 查看客户端同步差异和外部变更。 |
| 告警 | 查看失败、阻断、恢复类告警。 |
| 受控运维动作 | 对清空队列、清本地缓存、批量重发提交审批演示。 |

1. 鉴权代理方案已确定。

## 8. 常见问题

### 为什么我点了删除、发抓取、清缓存，但后端没有变化？

当前默认是 mock 演示环境。高危动作只验证交互、二次确认和回执，不真实落库或执行。

### 为什么刷新浏览器后流程还在？

保存草稿会把流程定义写入浏览器 localStorage。换浏览器、清缓存或换设备后，本地草稿不会自动同步。

### 如何清空本地流程草稿？

在浏览器开发者工具中清理 localStorage 的以下 key：

```text
sjcj.flows.index
sjcj.flow.*
```

### 为什么发布被拦截？

当前发布门禁至少要求流程不为空，且采集节点有源 URL 和输出表。先点击被配置的采集节点，在右侧补齐字段后再发布。

### 为什么构建出现 Rolldown annotation 警告？

该警告来自 Element Plus 依赖中的 `/* #__PURE__ */` 注释位置，当前构建退出码为 0，不影响产物生成。若后续升级 Vite/Rolldown 或 Element Plus，可再单独处理。
