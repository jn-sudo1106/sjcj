# 青龙智能采集中心 · 已实现功能文档

> 版本对应里程碑 P0 / M1 / M2 / M3 / M4 / M5(含 M5a·M5b) / M5.5 全部完成，并已补齐一级首页「采集资产总览」。

> 默认入口：**http://47.120.11.60:2806/sjcj/#/overview**；流程画布入口仍为 `#/canvas`。

## 1. 系统概述

数据采集平台的独立重构前端，品牌「青龙智能采集中心」。以「采集资产总览」作为一级首页，把采集链路的**配置、资产、规则、指标、运行、监控**整合为一个独立工作台，覆盖「看总览 → 配一条采集链路 → 试跑 → 看落表数据 → 追溯运行 → 运维监控」的完整闭环（mock 闭环已跑通）。

- **技术栈**：Vue 3 + Vite + TypeScript + Element Plus + Pinia + vue-router（hash 模式）。
- **流程画布为自绘 SVG**（非第三方画布库），精确控制节点 / 连线 / 插入点 / 拖拽重排。
- **导航分组**：首页（采集资产总览）· 工作台（流程画布）· 资产（采集 / 规则 / 指标）· 运维（数据查看 / 运行记录）· 工具（监控）。

## 3. 功能模块

### 3.1 采集资产总览 `/overview`

一级首页用于快速判断采集资产总体状态，并承接到各业务模块下钻。

- **KPI 总览**：采集资产总数、在线采集源、今日采集任务、成功率、告警数量、近 7 日新增资产；卡片支持跳转采集资产、运行记录、监控等页面。
- **采集资产全景**：按设计稿还原中心「统一数据平台」与数据库、API、文件、MQ、网页采集、第三方平台 6 类资产关系；图标使用 `设计稿/原型设计/采集资产图标合集/` 处理后的本地 PNG 资产。
- **采集任务趋势**：近 7 日 / 近 30 日切换，抓取量与成功量用分组柱状图展示。
- **资产类型分布**：展示二级分类占比（如 支付宝评论、天天基金、雪球、公告、行情、微博、新闻），不再只停留在基金类 / 股票类 / 舆情类一级口径。
- **重点采集源**：按数据量排序展示 Top 采集源、类型、负责人、状态、最近同步和质量评分。
- **实时运行动态**：展示最近任务动态；底部与左侧重点采集源、右侧告警/周期分布列保持同高对齐。
- **告警与周期分布**：右侧展示紧急/重要/一般/提示告警概览，以及按采集周期聚合的分布。

### 3.2 流程画布 `/canvas`

可视化编排单条采集链路，并在 mock 下跑通「网页抓取」全闭环。

- **画布（FlowBoard，自绘 SVG）**：链路节点 + 连线渲染；节点**拖拽重排**；运行态徽标（待运行 / 运行中 / 完成 / 失败）；顶部显示流程名 + **切换流程**下拉 + 跳运行记录。
- **左侧节点库（NodeLibrary）**：分组陈列 + **搜索过滤** + **拖拽入画布**。节点分组：
  - 采集源：网页抓取(90)、浏览器抓取、公众号抓取、文件下载(95)、Python 抓取(170)
  - 解析：文件解析、OCR 识别(150·规划)、AI 提取(155·规划)
  - 字段处理：字段抽取 / 结构化映射、字段清洗 / 格式转换、去重处理
  - 校验 / 规则：完整性 / 阈值校验(300)、规则处理、规则 Trace
  - 输出：落表输出、指标引用
  - 通知：提取数据发邮件(规划)、异常告警(规划)
- **右侧检查器（rc-* 原生方块样式，数据驱动）**：
  - **NodeInspector**：采集节点 = **四步方块 stepper（源 / 表 / 登录 / 完成）**，含抓取类型下拉（网页抓取 / 浏览器抓取 / 公众号抓取 / 文件下载 等）、URL 参数编辑器（支持 `$PARAM$` 识别、绑定与笛卡尔积预览）、运行设置折叠区（代理/断点续爬/登录）、选目录 / 配定时 等入口。对于独立能力节点实行**固定输出表与固定队列锁定**；「使用配置 / 输出表 / 输入参数」下拉联动 config/entry/param；表详情随选中表动态；凭据脱敏。规则节点 base / fields 下拉接 `ruleApi`。无选中时显示空态。
  - **EdgeInspector**：连线子步骤行、上下文、启停开关，保存映射到 `item/next/*`。
- **编辑动作（flow store）**：插入 / 复制 / 上移下移 / 启停 / 删除 / 改名 / 采集配置回写 / 基础行 / 字段行 / 连线行 / 连线上下文等。
- **新建流程 / 初始化画布（M5.5）**：顶栏「＋新建流程」对话框（`NewFlowDialog`）——自然语言描述 + 意图 chips → `flow/recommend` 关键词匹配返回**预置链路 + 推荐理由 + 备选**（4 类意图：公共网页 / 登录站点 / 文件下载解析 / 公告规则；未命中回落空白）。支持**空白 / 标准**两种初始化；空白画布有引导卡。二期换真 LLM 界面零改动。
- **流程持久化**：`FlowDef` 序列化 + `flowApi`（save / load / list，localStorage）+ 启动恢复 + 切换流程。
- **发布门禁**：`validateFlow` —— 空链路、采集节点缺 URL / 输出表 → 不可发布。
- **mock 试跑闭环**：`trial()` 生成 run_id + task、`setTimeout` 模拟节点 待运行→完成 流转、生成落表数据；**试跑 → 节点变绿 → 运行记录 → 数据查看，run_id 贯穿**。
- **顶部动作**：保存草稿 / 发布 / 试跑（经动作总线）。

### 3.3 采集资产 `/collect`（四 Tab）

| Tab | 功能 |
|---|---|
| **源（SourceTab）** | 左侧分类树（CategoryTree，已接入 API）+ 高密度源列表；**源详情抽屉**（26 字段 + 凭据脱敏 + 子步骤 + 外部变更）；**新建源四步向导**（去除了标签与源默认配置，归拢至节点）；批量操作 + 写类二次确认占位；**模板源批量导入**（已迁入网站详情侧栏）；行内查询 / 变更菜单。源态在画布区提供**原始文件视图**。 |
| **配置（ConfigTab）** | 配置列表 + 详情。 |
| **实体（EntryTab）** | 实体表列表 + 实体编辑器（字段定义）。 |
| **参数（ParamTab）** | 参数列表（列表 / 日期 / 序列三类）+ 生成值预览。一级页签作为集中管理入口保留，新建与编辑抽屉可被画布节点内复用。 |

### 3.4 规则资产 `/rules`

- **规则组面板（RuleGroupPanel）** + 发布门禁侧栏。
- **规则列表** + **规则详情抽屉（RuleDetailDrawer）**：表达式 / 共享配置 / 测试集 / 引用关系。
- **函数测试器（FunctionTester）**：内嵌**真求值器**（`mock/rules.ts` 的 `mockEvaluate`），支持 IF / AND / OR / NOT / 比较 / CONTAINS / LEN，不支持语法回落「待接口」态；可填 context + 表达式即时求值。

### 3.5 指标中心 `/metrics`

- 指标数据集（dataset）/ 指标定义（measure）**两层结构** + 口径回溯链路。

### 3.6 数据查看 `/data`

- 表选择 + SQL 白名单查询 + 列值指针 + 原始文件查看；显示行 = runtime 落表数据叠加静态 mock（试跑产生的数据在此可见）。

### 3.7 运行记录 `/runs`

- run_id 时间线 + 节点任务明细 + 指针追溯；合并 runtime 试跑运行与静态 mock（试跑生成的 RUN 在此出现）。

### 3.8 监控工具 `/tools`

- 健康卡 + MQ 队列 / 同步状态 / 告警 + 受控运维动作审批（只读运维视角）。

## 4. 数据模型（`api/types.ts`）

源 `Source`(26 字段) · 分类 `SourceCategory` · 配置 `Config` · 实体 `EntryType`/`EntryField` · 参数 `Param` · 子步骤 `Step` · 凭据 `CredentialRef` · 日志 `SourceLog` · 任务 `TaskInst`；规则 `Rule`/`RuleGroup`/`RuleGate`/`RuleTestCase`/`SharedConfig`/`EvalResult`；指标 `Dataset`/`Measure`；数据查看 `DataTableMeta`/`DataRow`；运行 `RunRow`/`RunNode`；监控 `HealthCard`/`MqQueue`/`SyncRow`/`AlarmRow`；首页总览 `OverviewSummary`/`OverviewSlice`/`TrendPoint`；工作台 `WorkbenchSummary`；通用 `Paged<T>`/`PageQuery`/`Ack`。
